RockPortfolio.com logo scroller fix
Date: 2026-08-25

WHAT CHANGED
1. Moved the logo scroller on BOTH index.html and about.html so it sits immediately below the site navigation/header and before each page's hero content.

   index.html order:
   Navigation -> Logo Scroller -> Enterprise Journey Management hero

   about.html order:
   Navigation -> Logo Scroller -> About / Resume hero

2. Replaced the previous CSS-transform marquee animation with the same core approach that proved reliable on torontosiggraph.org:
   - Native horizontal scroll container
   - JavaScript requestAnimationFrame() advances scrollLeft continuously
   - Seamless repeated logo groups
   - No dependency on CSS animation timing for movement

3. Fixed two likely desktop causes from the previous RockPortfolio version:
   - The old CSS explicitly disabled the marquee when the browser/Windows reported prefers-reduced-motion. This can make the strip appear completely static on one PC while moving on another.
   - The old JavaScript paused the marquee merely when the desktop mouse hovered over it. The revised version does NOT pause on hover; it pauses only when the user actively clicks/drags or touches the scroller.

4. Interaction behavior now mirrors the Toronto SIGGRAPH scroller:
   - Desktop: auto-scrolls continuously.
   - Desktop mouse drag: pauses while dragging, then resumes after ~600 ms.
   - Mobile/tablet touch: pauses immediately on touch, then resumes ~900 ms after release.
   - Vertical page scrolling remains available on touch devices.
   - Scrolling pauses when the browser tab is not visible.

5. Responsive behavior retained/refined in styles.css:
   - Full desktop logo sizes and spacing.
   - Smaller logo width/spacing at tablet and mobile breakpoints.
   - Hidden scrollbars while retaining a real scrollable container.

6. Normalized the supplied logo assets into browser-friendly filenames inside /images and updated BOTH HTML pages to use those files:
   - logo-ontario-health.png
   - logo-cibc.png
   - logo-rbc.png
   - logo-td.svg
   - logo-scotiabank.png
   - logo-telus.svg
   - logo-bell.png
   - logo-government-ontario.png
   - logo-acm-siggraph.png

   This also removes reliance on logo filenames that were referenced by the previous HTML but were not actually present in the attached ZIP.
